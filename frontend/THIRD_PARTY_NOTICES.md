# Raydium UI v3 public

The DEX swap layout and palette in `src/components/Defi/DexSwapPanel.tsx` and
`DexSwapPanel.css` were adapted from the panel and market composition of
[raydium-ui-v3-public](https://github.com/raydium-io/raydium-ui-v3-public),
revision `045a2a942711440b85e091ac313378a1e534f102`.

The implementation was rewritten for this project's Vite/React frontend,
Solana Devnet pools, existing wallet flow, and Vietnamese copy. No Raydium
logos, icons, or source components are included. The upstream project is
licensed under Apache-2.0; a copy is in `licenses/raydium-ui-v3.LICENSE`.
